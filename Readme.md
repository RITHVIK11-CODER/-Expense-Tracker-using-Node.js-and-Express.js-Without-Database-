# 📖 Project Description

The **Expense Tracker** is a modern web-based application developed using **Node.js**, **Express.js**, and **EJS**, following the **Model-View-Controller (MVC)** architecture. The application enables users to efficiently manage their daily income and expense transactions through a clean, responsive, and user-friendly interface.

Users can add, edit, and delete transactions while the application automatically calculates the **Total Income**, **Total Expenses**, and the **Current Balance** in real time.

This project is developed **without using any database**. All transaction data is stored temporarily in an **in-memory JavaScript array**, making it ideal for learning CRUD operations, Express.js routing, middleware, MVC architecture, and server-side rendering using EJS.

The application features a modern **Glassmorphism-inspired UI**, responsive layouts for desktops and mobile devices, smooth animations, form validation, custom 404 error handling, and an attractive dashboard that provides a clear overview of financial information.

This project serves as an academic implementation of Web Application Framework concepts and demonstrates how modern web applications are developed using Node.js and Express.js before integrating databases such as MongoDB or MySQL.

# ⚙️ Installation

## Clone the Repository

```bash
git clone https://github.com/your-username/ExpenseTracker.git
```

Move into the project directory

```bash
cd ExpenseTracker
```

Install dependencies

```bash
npm install
```
